Landing page de Direito do Consumidor e Bancário (penhora de bens e valores) (site estático, um único `index.html`).

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: **Add New → Project → Import** o repositório.
3. Framework Preset: **Other**. Não precisa de build command. Clique em **Deploy**.

O número de WhatsApp fica no início do `<script>`, na linha `var WA = '5567991991444';`.
